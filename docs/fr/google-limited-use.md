# Données utilisateur Google — usage limité (FairyBill)

L’utilisation par FairyBill des informations reçues des API Google respecte la [politique de données utilisateur des services API Google](https://developers.google.com/terms/api-services-user-data-policy), y compris les exigences **Limited Use**.

## Portées

L’application demande l’accès Gmail en lecture seule (`gmail.readonly`) pour :

- Rechercher les messages ressemblant à des factures.
- Lire les avis e-Transfer Interac si vous activez « Synchroniser e-Transfer ».

## Déclaration Limited Use

Les données Gmail servent **uniquement** aux fonctionnalités visibles dans l’application (liste, résumés). Nous ne les utilisons pas pour la publicité, ni pour entraîner des modèles non liés au service. L’extraction s’effectue sur l’appareil ; nous n’hébergeons pas de copie cloud de la boîte.

## Révocation

Déconnexion dans l’application ou retrait de FairyBill dans [Accès tiers](https://myaccount.google.com/permissions).
