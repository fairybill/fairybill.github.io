# Google 用户数据 — 有限使用说明（FairyBill）

FairyBill 对通过 Google API 收到的信息的使用遵守 [Google API 服务用户数据政策](https://developers.google.com/terms/api-services-user-data-policy)，包括 **Limited Use** 要求。

## 权限范围

应用申请 Gmail 只读权限（`gmail.readonly`），用于：

- 搜索并读取疑似家庭账单或公用事业账单的邮件；
- 在设置中开启「同步 e-Transfer」时，读取 Interac e-Transfer 相关邮件。

## Limited Use 声明

Gmail 数据**仅**用于应用内向用户展示的功能（账单列表、总结等）。不用于广告、不向无关第三方提供邮件内容用于其他目的、不用于训练与用户无关的通用模型。账单识别在设备上进行，我们不在云端保存邮箱副本。

## 撤销访问

在应用设置中断开，或在 [Google 账号 → 第三方访问权限](https://myaccount.google.com/permissions) 中移除 FairyBill。
